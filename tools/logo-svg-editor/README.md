# SPEED AD ロゴ SVG エディタ

ブラウザだけでSVG内の `path` を直接調整するための、小さなローカル編集ツールです。外部依存はありません。確定済みのS / P / E1 / E2 / D1 / A / D2を画面上から選んで読み込めます。

## 起動方法

リポジトリのルートで次を実行し、[http://localhost:8000/tools/logo-svg-editor/](http://localhost:8000/tools/logo-svg-editor/) を開きます。

```powershell
python -m http.server 8000
```

`file://` で直接開くと、ブラウザのES Modules制約により正しく動作しない場合があるため、HTTPサーバーの利用を標準とします。

## 操作

1. 「確定文字を選ぶ」から対象を選びます。起動時は最新のSを自動で読み込みます。
   - 編集元は `assets/` に同梱した確定SVGです。
   - 任意のSVGはファイル選択またはドラッグ＆ドロップでも読み込めます。
2. 左の一覧またはキャンバス上のパーツを選び、サブパスを選択します。
   - v10の下部にある紺色パーツは「パス 1 / 4」です。
3. ノード（黄色はアンカー、白はC制御点）をドラッグするか、右側の座標欄で値を入力します。
   - 「ポイントサイズ」で小・中・大を切り替えられます。小表示でも透明な操作領域が確保されるため、見た目を邪魔せずドラッグできます。
4. 選択アンカーへ入る線分を必要に応じて「直線化」「曲線化」します。矢印キーは1px、Shift＋矢印キーは10pxの移動です。
5. 「編集済みSVGをダウンロード」で `-edited.svg` の別名ファイルを保存します。Ctrl＋Z / Ctrl＋Y、または Ctrl＋Shift＋Z で履歴を操作できます。
6. 編集を破棄する場合は「この文字を元の形に戻す」を押します。

## 対応範囲と既知制約

- 絶対座標の `M` / `L` / `C` / `Z` パスを編集対象にします。相対座標、`Q`、`A`、`H`、`V`、transform付きパスなどは対象外です。
- 表示前に `script`、`foreignObject`、イベント属性、外部URL参照を削除します。`path` 以外のSVG要素は表示・書き出しに残りますが、編集一覧には含めません。
- 複雑なクリップ、マスク、CSS参照を使うSVGでは見た目が完全には再現されないことがあります。
- デスクトップでは操作パネル・キャンバス・インスペクターが画面内に固定され、各一覧を個別にスクロールできます。
