# SPEED AD 名刺デザイン 30案

現行のSPEED ADブランドと公開仕様をもとにした、比較・選定用の名刺サンプルです。

## 内容

- 30コンセプト
- 各コンセプトに表面・裏面
- 名刺実寸 `91 × 55 mm`
- ブラウザ表示用HTML
- A4横・1案1ページの印刷用CSS
- `speed-ad.com` に遷移するQRコード

## 確認方法

`index.html` をブラウザで開いて確認します。印刷画面で「背景のグラフィック」を有効にすると、A4横の比較資料としてPDF保存できます。

同梱の `export.cjs` は、PlaywrightとGoogle Chromeを使って一覧PNGと30ページPDFを再生成します。

## 差し替え箇所

個人情報は `cards.js` 冒頭の `profile` を編集します。

- 会社名
- 部署
- 役職
- 氏名
- 電話番号
- メールアドレス
- Webサイト

現在の氏名・電話番号・メールアドレスはサンプルです。発注・印刷前に必ず正式情報へ差し替えてください。

## 表現の根拠

- ブランドカラー: 既存SPEED ADロゴ
- 主コピー: `スピードをアドバンテージに。`
- 基本機能: `WEBアンケート`、`名刺情報のデータ化`、`御礼メール`
- 利用フロー: `準備`、`QR回答`、`名刺撮影`、`追客`

料金、無料、最短、業界最安値など、公開条件の確認が必要な強い訴求は名刺面から外しています。
