サービスの流れ

登録からデータ活用まで、6ステップでスムーズに

  1. 01

    アカウント登録

    アカウント登録後、利用に必要な基本情報を設定します。

  2. 02

    アンケート作成・公開

    目的に合わせてアンケートを作成し、回答画面を公開します。

  3. 03

    QRコード発行

    回答用QRコードを発行し、Webや印刷物で共有します。

  4. 04

    回答・名刺取得

    回答者がアンケートに回答し、名刺画像を撮影・送信します。

  5. 05

    データ確認・レビュー

    回答内容とデータ化された名刺情報を、一覧で確認します。

  6. 06

    CSVエクスポート

    確認済みデータをCSV出力し、営業フォローや社内共有に活用します。
