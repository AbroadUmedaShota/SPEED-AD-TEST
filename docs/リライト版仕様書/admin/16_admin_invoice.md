## 1. 文書目的

- 本書は、請求書管理（アカウントと発行月の組み合わせで作成する月次請求書の管理）の要件を定義する。
- 全画面に共通する権限、UI 規則、監査ログ、通知、用語は共通編を参照する。本書は本画面に固有の要件を扱う。
- アンケート単位の請求の確認は本書の対象外とし、`15_admin_billing.md` で扱う。
- 本書は請求管理とは別画面とする前提で記述する。1 本化の判断は §11 で扱う。

## 2. 画面概要

- アカウントと発行月の組み合わせで作成する月次請求書を一覧で確認する画面。
- 請求書 1 通ごとの内訳（プレミアム利用料、名刺データ化費用、お礼メール送信費用、請求合計）を確認する。
- 現行画面は一覧データが表示されない状態にあり、本書は画面単位の整理として要件を定義する（§8）。

## 3. 想定利用者と対象範囲

### 3.1 想定利用者

- 運営全体を管理する Lv3・Lv4。月次の請求書の内容確認と、顧客への提示・送付の判断を行う。

### 3.2 対象範囲

- 月次請求書の一覧・検索
- 請求内訳の確認

### 3.3 対象外

- アンケート単位の請求の確認とクーポンの事後適用（`15_admin_billing.md`）
- クーポンの発行・適用（`17_admin_coupon.md`）
- 請求書の顧客側での表示（利用者向け画面で扱う）

## 4. 画面要件

### 4.1 共通構成

- ヘッダー、サイドバー、パンくずを表示する（`01_admin_common_ui.md` §2）。
- 画面タイトルを表示する。
- 画面は上から、検索条件、請求書一覧の順に配置する。

### 4.2 一覧表示

各請求書について次を表示する。

| 表示項目 | 内容 |
| --- | --- |
| 発行月 | 請求書の発行対象月 |
| 会社名 | 請求先の会社 |
| プレミアム利用料 | プレミアムプランの契約に基づく定額分（月額 10,000 円・税別） |
| お礼メール送信費用 | お礼メール送信数に対する従量分（1 通 1 円・無料 100 件を控除） |
| 請求合計 | 上記を合算した金額 |

- 1 行が 1 通の請求書（アカウントと発行月の組み合わせ）に対応する。
- 金額は 3 桁ごとのカンマ区切りで表示し、単位を「円」とする（`01_admin_common_ui.md` §9）。
- 一覧はページングと表示件数の選択に対応する（`01_admin_common_ui.md` §4.3）。
- 各列で昇順・降順の並び替えができる。

### 4.3 検索

| 条件 | 種別 | 内容 |
| --- | --- | --- |
| 会社名 | 検索 | 部分一致で対象を絞り込む |
| 発行月 | 検索 | 年月を指定して絞り込む |

条件をまとめて初期状態へ戻す操作を用意する。

### 4.4 請求内訳の確認

- 一覧から対象を選択すると、利用者向け画面が表示する請求書をそのまま表示する。管理者用に別の体裁を用意せず、利用者が見るものと同一の画面を読み込む。
- 請求書には発行日・請求書番号・宛名・差出人・件名・小計（課税対象）・消費税等・合計請求金額・振込先・支払期日・ご請求明細を表示する。
- ご請求明細の行は、プレミアム利用料（アカウント単位）、名刺データ化費用（アンケート単位）、お礼メール送信費用（アンケート単位）、クーポン値引きで構成する。明細名は利用者側の請求書が認識する名称と一致させる。名称が一致しないと、利用者側の請求書で種別ごとの小計が出ない。
- 請求書を別タブで開く導線を用意する。
- 一覧には、発行月・会社名・プレミアム利用料・名刺データ化費用・お礼メール送信費用・請求合計（税込）を表示する。プレミアムプランを契約していないアカウントの行は、プレミアム利用料の欄を「—」とする（`01_admin_common_ui.md` §9 の該当なしの表記）。

### 4.5 検討中の要件

| 要件 | 内容 |
| --- | --- |
| 請求書の出力 | 請求書を書面の形式で出力する。出力形式と記載項目は §11 で確定する |

## 5. 通知

本画面の操作を起点とする通知・メールの発火はない（`03_admin_common_notifications.md` §2）。

## 6. 権限とデータ範囲

| 権限レベル | 扱い |
| --- | --- |
| Lv1 | 本画面へアクセスできない。サイドバーに項目を表示しない |
| Lv2 | 本画面へアクセスできない。サイドバーに項目を表示しない |
| Lv3 | 全範囲の請求書を表示できる |
| Lv4 | 全範囲の請求書を表示できる |

- 本画面は金銭情報を扱うため、Lv2 以下はテナント分離により到達しない（`00_admin_common_permissions.md` §3）。
- 権限判定はサーバー側で行う（`00_admin_common_permissions.md` §9.1）。

## 7. 状態と挙動

### 7.1 初期表示

- 検索条件は未入力の状態で表示する。
- 一覧の既定の並び順は請求月の降順とし、直近の請求月を先頭に表示する。
- 表示件数の既定は 50 件とする。

### 7.2 該当が 0 件の場合

- 一覧の位置に該当なしの旨を表示する。

### 7.3 金額の再計算

- 請求管理（SCR-A-006）でアンケート単位の請求金額を補正した場合、対応する月次請求書の合計へ反映する。反映の契機は §11 で確定する。

## 8. 現行画面からの引き継ぎ

現行画面 `/admin/invoice` は検索欄と一覧の列は表示されるが、一覧データがエラーで表示されない状態である（2026-07-23 および 2026-07-24 の両日で同一の状態を確認）。動作する機能を裏取りできていないため、引き継ぎの最低線は列構成と検索に限る。

| 現行の要素 | 本書での扱い |
| --- | --- |
| 一覧の列構成 | §4.2 |
| 会社名・請求月による検索 | §4.3 |

一覧の表示不良そのものは本書の対象外とし、実装時に解消する。

## 10. 画面確認観点

モックアップ上で次を確認する。

- [ ] 一覧に発行月・会社名・プレミアム利用料・名刺データ化費用・お礼メール送信費用・請求合計が表示される
- [ ] プレミアムプランを契約していないアカウントの行で、プレミアム利用料の欄が「—」になる
- [ ] 金額が 3 桁ごとのカンマ区切りで表示され、単位が「円」である
- [ ] 会社名と発行月による検索が機能する
- [ ] 一覧から対象を選択すると請求内訳が表示される
- [ ] 請求合計がプレミアム利用料・名刺データ化費用・お礼メール送信費用・クーポン値引きの合算として表示される
- [ ] 初期表示の並び順が発行月の降順である
- [ ] 該当が 0 件のとき、一覧の位置に該当なしの旨が表示される
- [ ] Lv2 以下でログインした場合、本画面の URL へ直接アクセスしても表示されない

## 11. 画面外の確認事項

| # | 項目 | 内容 |
| --- | --- | --- |
| 1 | 請求書とアンケートの単位関係 | 決着済み（2026-08-04）。1 通の請求書へ、同じアカウント・同じ請求月のアンケートの請求を束ねる。 |
| 2 | 請求管理との 1 本化 | 請求管理と 1 画面に統合するか、別画面のまま運用するかを確定する。統合する場合、本書を `15_admin_billing.md` へ統合する。 |
| 3 | 画面 ID の採番 | 別画面として存続する場合の画面 ID を採番する。 |
| 4 | 請求内訳の項目 | 決着済み（2026-08-04）。プレミアム利用料・名刺データ化費用・お礼メール送信費用・クーポン値引きの 4 種を明細の行として持つ。名称は利用者側の請求書が認識する明細名に合わせる。消費税は小計（課税対象）と分けて表示し、合計は税込とする。 |
| 5 | 請求書の確定タイミング | 月次請求書をいつ確定するかを確定する。確定後にアンケート単位の請求を補正した場合の再計算の扱いを併せて決める。 |
| 6 | 請求書の出力形式 | §4.5 を導入する場合、出力形式（PDF 等）と記載項目、押印・適格請求書の要件を確定する。 |
| 7 | 顧客側の請求書表示との整合 | 決着済み（2026-08-04）。同一のデータとし、本画面は利用者向け画面の請求書をそのまま表示する。 |
| 8 | 現行の表示不良の原因 | 一覧データが表示されない原因を開発側へ確認する。データ不備か実装不具合かで、移行時の対応が変わる。 |
